## Types of Constructors
| Constructor Type | Purpose                |
| ---------------- | ---------------------- |
| Default          | No arguments           |
| Parameterized    | Initialize with values |
| Copy             | Copy object            |
| Move             | Transfer ownership     |
| Defaulted        | Auto-generated         |
| Deleted          | Prevent creation       |

> Parametrized construcrtors can be many.

### EXAMPLES:
1. 
```cpp
class Student {
    int id;
public:
    Student() { 
        cout <<"Default Constructor" ;
     }
    Student(int x) { 
        cout <<"Parametrized Constructor" ;
        id = x; 
    }
    Student(const Student &s) {
        cout <<"Copy Constructor" ;
        id = s.id;
    }
    Student(const Student &s) {
        cout <<"Move Constructor" ;
        id = s.id;
        s.id = NULL;
    }

    Student() = delete; // Prevents object creation.

};
```
