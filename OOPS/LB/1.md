## Types of Constructors
- A constructor is a special member function of a class that is automatically called when an object is created to initialize it.
> If you define any constructor, the compiler does NOT generate a default constructor.

| Constructor Type | Purpose                |
| ---------------- | ---------------------- |
| Default          | No arguments           |
| Parameterized    | Initialize with values |
| Copy             | Copy object            |
| Move             | Transfer ownership     |
| Defaulted        | Auto-generated         |
| Deleted          | Prevent creation       |

> Parametrized construcrtors can be many.

### EXAMPLES:
1. 
```cpp
class Student {
    int id;
public:
    Student() { 
        cout <<"Default Constructor" ;
     }
    Student(int x) { 
        cout <<"Parametrized Constructor" ;
        id = x; 
    }
    Student(const Student &s) {
        cout <<"Copy Constructor" ;
        id = s.id;
    }
    Student(const Student &s) {
        cout <<"Move Constructor" ;
        id = s.id;
        s.id = NULL;
    }

    Student() = delete; // Prevents object creation.

};
```

## SHALLOW COPY :
- IF Your class HAS a pointer member => SHALLOW COPY IS POSSIBLE.

- 🔍 Why did this happen?
    - s1.marks and s2.marks point to the same memory location
    - Changing one affects the other
    - This is shallow copy behavior.

### ⚠️ Problem with Shallow Copy
- When objects are destroyed:

~Student() {
    delete marks;
}
> 👉 Both objects try to delete the same memory → ❌ crash (double free)

## Does Constructor return any Value?
Yes, Constructor return the current instance of a class. Because they are used to initialize an object but constructor does not have any signature of return type

## STATIC KEYWORD :
- The keyword static is used to control memory allocation, lifetime, and scope of variables and functions.
- Only one copy exists in memory, shared by all objects.

1. 🔸 1️⃣ Static Data Members (Variables)
- A static data member is shared by all objects of the class.
```cpp
class Student {
public:
    static int count;

    Student() {
        count++;
    }
};

int Student::count = 0;  // Mandatory definition
```

2. 2️⃣ Static Member Functions
- A static function:
    - Can access only static data members
    - Does NOT need an object to be called
```cpp
class Demo {
public:
    static void show() {
        cout << "Hello from static function";
    }
};
```

3. 🔸 3️⃣ Static Local Variables
- A variable declared static inside a function:
```cpp
void counter() {
    static int count = 0;
    count++;
    cout << count << endl;
}
```
- ✔ Value is preserved between function calls
- ✔ Initialized only once

4. 🔸 4️⃣ Static Objects
```cpp
class Test {
public:
    Test() {
        cout << "Constructor\n";
    }
};

void func() {
    static Test t;
}
```
- ✔ Object created only once
- ✔ Destructor runs at program termination.
- They are allocated storage in the data segment or BSS segment of the memory.

| Context           | Meaning of `static`      |
| ----------------- | ------------------------ |
| Local variable    | Retains value            |
| Class data member | Shared by all objects    |
| Class function    | No object needed         |
| Global variable   | File-level visibility    |
| Function          | Internal linkage         |
| Object            | Single instance lifetime |

## this 
- this is a pointer to the current object.
- this is an implicit pointer available inside non-static member functions

### Uses
1. 1️⃣ Resolve Name Ambiguity (MOST COMMON)

2. 2️⃣ Return Current Object (Method Chaining)
```c
class Counter {
    int value;
public:
    Counter& inc() {
        value++;
        return *this;
    }
};

Counter c;
c.inc().inc().inc();
```
- ✔️ Enables fluent / chained calls

3. 3️⃣ Pass Current Object to Another Function
```c
class Test {
public:
    void show() {
        print(*this);
    }
};

void print(Test t) {
    cout << "Object printed\n";
}
```
- ✔️ Useful for callbacks, helpers

4. 5️⃣ Compare Current Object with Another
```c
class A {
public:
    int x;
    bool isSame(A& other) {
        return this == &other;
    }
};
```

> this is an implicit pointer that holds the address of the current object and is used to access its members.

## Dynamic binding : 
- 👉 the function call is resolved at runtime, based on the object’s actual type — not the pointer type.
    - ✔️ Function chosen at runtime
    - ✔️ Based on actual object type

### 🔹 How Dynamic Binding Works Internally (Conceptual)
- Compiler creates a vtable (virtual table)
- Each object stores a vptr
- At runtime:
    - Follow vptr
    - Lookup function in vtable
    - Call correct function

### 🔹 Requirements for Dynamic Binding in C++
- 1️⃣ Inheritance
- 2️⃣ Base class pointer/reference
- 3️⃣ Virtual function

❌ Miss even one → no dynamic binding

### 
- ❓ Are constructors dynamically bound?
❌ No
Constructors are statically bound

- ❓ Are destructors dynamically bound?
✔️ Yes if declared virtual
