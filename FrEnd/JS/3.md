## DOM
- The DOM is a programming interface that represents an HTML document as a tree structure so JavaScript can manipulate it.

## Event bubbling 
- is a mechanism where an event starts from the target element and propagates upward through its parent elements to the document.
> 📌 Bottom → Top ⬆️

```js

<div id="parent">
  <button id="child">Click</button>
</div>

document.getElementById("parent").addEventListener("click", () => {
  console.log("Parent clicked");
});

document.getElementById("child").addEventListener("click", () => {
  console.log("Child clicked");
});


```
- 👉 Clicking the button prints:
```yml
Child clicked
Parent clicked
```
- ✔ Event bubbles from child → parent

### 🔹 Stop Event Bubbling 🚫
```js
document.getElementById("child").addEventListener("click", (e) => {
  e.stopPropagation();
});
```
- ✔ Event won’t reach parent

## Event capturing 
- (also called trickling) is the phase where an event starts from the top (document/window) and travels down to the target element.
> 📌 Top → Bottom ⬇️
- Event Flow (Full Picture 🔥)
    - 1️⃣ Capturing phase (document → target)
    - 2️⃣ Target phase
    - 3️⃣ Bubbling phase (target → document)
```js
<div id="parent">
  <button id="child">Click</button>
</div>

document.getElementById("parent").addEventListener(
  "click",
  () => console.log("Parent (capture)"),
  true // 👈 enables capturing
);

document.getElementById("child").addEventListener(
  "click",
  () => console.log("Child")
);
```
```yml
Parent (capture)
Child
```
> ✔ Default is bubbling (false)

## Event delegation 
- is a technique where a single event listener is added to a parent element to handle events for its child elements.
> 📌 Works because of event bubbling
```js
<ul id="list">
  <li>Apple</li>
  <li>Banana</li>
  <li>Mango</li>
</ul>

document.getElementById("list").addEventListener("click", (e) => {
  if (e.target.tagName === "LI") {
    console.log(e.target.textContent);
  }
});
```

- ✔ One listener
- ✔ Handles all <li> clicks
- ✔ Even works for dynamically added elements

## 🔹 event.preventDefault()
- preventDefault() stops the browser’s default behavior for an event.
- It does NOT stop the event itself — only the default action.

### Example: Form submit
```js
<form id="form">
  <button type="submit">Submit</button>
</form>

document.getElementById("form").addEventListener("submit", (e) => {
  e.preventDefault();
  console.log("Form submitted via JS");
});
```
- ✔ Prevents page reload
- ✔ Used in SPA apps (React, Vue)

## 🔹 event.stopPropagation()
- stopPropagation() stops the event from propagating (bubbling or capturing) further in the DOM.
- 📌 It controls event flow, not default behavior.
- Example
```js
<div id="parent">
  <button id="child">Click</button>
</div>

document.getElementById("parent").addEventListener("click", () => {
  console.log("Parent clicked");
});

document.getElementById("child").addEventListener("click", (e) => {
  e.stopPropagation();
  console.log("Child clicked");
});
```
- 📤 Output:
> Child clicked
- ✔ Parent does NOT receive event

## 🔹 Debouncing
- Debouncing ensures a function runs only after a specified delay once the event stops firing.
- 📌 “Wait until the user stops”
- Debounce Example
```js
function debounce(fn, delay) {
  let timer;
  return function (...args) {
    clearTimeout(timer);
    timer = setTimeout(() => fn.apply(this, args), delay);
  };
}

const search = debounce(() => {
  console.log("API call");
}, 500);
```
- ✔ Prevents unnecessary API calls
- ✔ Executes once after delay

## 🔹 Throttling
- Throttling ensures a function runs at most once in a specified time interval.
- 📌 “Run every X ms, no matter what”
> Throttling limits how often a function can execute over time.

## 🔹 How to Optimize JavaScript Performance?

1. 1️⃣ Minimize DOM Manipulation (VERY IMPORTANT 🔥)
- DOM operations are expensive.
- ❌ Bad
```js
for (let i = 0; i < 1000; i++) {
  document.body.innerHTML += "<div></div>";
}
```
- ✅ Better
```js
let html = "";
for (let i = 0; i < 1000; i++) {
  html += "<div></div>";
}
document.body.innerHTML = html;
```
- ✔ Batch DOM updates
- ✔ Reduce reflows & repaints

2. 2️⃣ Use Event Delegation
- ❌ Bad (many listeners)
```js
items.forEach(item => {
  item.addEventListener("click", handler);
});
```
- ✅ Good
```js
parent.addEventListener("click", e => {
  if (e.target.matches(".item")) handler();
});
```
- ✔ Fewer listeners
- ✔ Better memory usage

3. 3️⃣ Debounce & Throttle Expensive Events 🔥
- For:
    - Scroll
    - Resize
    - Input search
- const optimizedSearch = debounce(searchAPI, 500);
- ✔ Fewer function calls
- ✔ Prevents UI lag
