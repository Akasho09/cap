## What is React?
- A JavaScript library for building fast, interactive user interfaces using a component-based approach. It updates the UI efficiently with a Virtual DOM.

## Core Concepts (must-know)
1. Components: Reusable UI blocks (function components are standard)
2. JSX: HTML-like syntax inside JS
    - JSX (JavaScript XML) is a syntax extension for JavaScript that allows us to write HTML-like code inside JavaScript, which React converts into JavaScript function calls.
3. Props: Read-only inputs to components
4. State: Mutable data managed inside components
5. Hooks: Functions that add state & lifecycle features

## Hooks (interview gold)
1. useState – local state
2. useEffect – side effects (API calls, subscriptions)
3. useContext – global state without prop drilling
4. useMemo / useCallback – performance optimization
5. useRef – DOM refs & mutable values

## Virtual DOM (why React is fast)
- React keeps a lightweight copy of the DOM
- Diffs old vs new Virtual DOM
- Updates only what changed in the real DOM

## Component Types
- Functional components ✅ (preferred)
- Class components ❌ (legacy)

## Controlled vs Uncontrolled
- Controlled: React controls input value via state
- Uncontrolled: DOM manages state via refs

## 1️⃣ Lifting State Up
- When multiple child components need the same state, move (lift) that state to their closest common parent.
- Why it’s needed:
    - To keep data in sync
    - Avoid duplicated state
    - Single source of truth
- Example (classic interview one):
```jsx
function Parent() {
  const [count, setCount] = useState(0);

  return (
    <>
      <ChildA count={count} />
      <ChildB setCount={setCount} />
    </>
  );
}
```

2. 2️⃣ Conditional Rendering
- Rendering UI based on a condition (if/else logic inside JSX).
- Common patterns:
1. ✔ Using if
```jsx
if (!isLoggedIn) {
  return <Login />;
}
return <Dashboard />;
```
2. ✔ Using ternary
```jsx
{isLoggedIn ? <Dashboard /> : <Login />}
```

3. ✔ Using &&
```jsx
{isAdmin && <AdminPanel />}
```
- 📌 Interview tip:
- && is used when you want to render something or nothing.

3. 3️⃣ List Rendering with key
- Rendering arrays using .map() and assigning a unique key to each item.
- Example:
```jsx
users.map(user => (
  <li key={user.id}>{user.name}</li>
))
```
- Why key is important:
    - Helps React identify which items changed
    - Improves reconciliation performance
    - Prevents UI bugs
- 🚫 Bad practice
- key={index} // avoid unless list is static
- 📌 Interview line:
- “Keys help React efficiently update the DOM by tracking list items.”

4. 4️⃣ Composition Over Inheritance
- React prefers building components by combining them, not extending them like OOP inheritance.
- Instead of inheritance ❌
    - class Button extends Component {}
- Use composition ✅
```jsx
function Card({ children }) {
  return <div className="card">{children}</div>;
}

<Card>
  <h2>Title</h2>
  <p>Content</p>
</Card>
```
- Why React prefers composition:
    - More flexible
    - Easier to reuse
    - Cleaner architecture
- 📌 Golden interview quote:
    - “React uses composition to reuse behavior instead of inheritance.”

## Performance Tips
1. Memoize heavy components (React.memo)
2. Avoid unnecessary re-renders
3. Use keys properly in lists
4. Split code with lazy + Suspense

## Higher-Order Components (HOCs)
- A Higher-Order Component (HOC) is a function that takes a component and returns a new enhanced component.
