## portfolio : 
- showcase performance optimization, and UI/UX skills using modern React and Next.js.
- Optimized Core Web Vitals achieving:
- FCP: 0.94s
    - Time taken for the first text, image, or content to appear on the screen.
- LCP: 1.27s
    - Time taken to load the main visible content (hero image, main heading, banner).
- CLS: 0
    - Measures unexpected UI movement while the page loads.
- TTFB: 0.14s
    - How long the server takes to send the first byte of data after a request.
- Used Next.js **Image Optimization** (sharp) and code-splitting to reduce render-blocking resources.
- Styled responsive layouts using Tailwind CSS, ensuring consistency across devices.
- Integrated GitHub API (Octokit) to dynamically showcase projects and activity.
- Monitored real-user performance using Vercel Analytics & Speed Insights.
