## 🔹 What is a Subnet?
- A subnet divides a large network into smaller logical networks.
- 👉 Instead of one huge network, you get multiple smaller networks, each called a subnet.

### 🔹 Subnet Mask Explained
- A subnet mask defines:
    - Which part is network
    - Which part is host
- IP Address:   192.168.1.10
- Subnet Mask:  255.255.255.0
- This means:
    - Network part → 192.168.1
    - Host part → .10

 ## Load Balancer?
-  A Load Balancer is a network device or software that distributes incoming network traffic across multiple servers to ensure:
✅ High availability
✅ Better performance
✅ No server overload

### 🔹 Types of Load Balancers
1. 1️⃣ Hardware Load Balancer
- Physical device
- Very fast but expensive
- Used in large data centers

2. 2️⃣ Software Load Balancer
- Software-based
- Runs on normal servers
- Examples:
    - Nginx
    - HAProxy
    - Apache

3. 3️⃣ Cloud Load Balancer
- Provided by cloud platforms
- Auto-scalable
- Examples:
    - AWS ELB / ALB
    - Google Cloud Load Balancer
    - Azure Load Balancer
