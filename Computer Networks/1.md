## Computer Networking 
- Computer Networking is the practice of connecting multiple **computing devices** (computers, servers, routers, etc.) to share data, resources, and services using communication protocols.
- 🔹 Real-Life Example:
    - Internet
    - College LAN
    - Office Wi-Fi
    - Mobile networks (4G/5G)

### 🔍 Difference Between localhost and 127.0.0.1
1. 🟢 1. localhost
- Hostname (name)
- Human-friendly name for the local machine
- Resolved using DNS or hosts file
- Can map to:
    - 127.0.0.1 (IPv4)
    - ::1 (IPv6)

2. 🔵 2. 127.0.0.1
- IP address
- Called the loopback address
- Always points to your own machine
- Part of IPv4 standard (127.0.0.0/8 range)

## 🌐 Types of Computer Networks
1. 🔹 1. PAN (Personal Area Network)
- A Personal Area Network connects devices within a very small range (1–10 meters), usually around one person.
- 📌 Examples:
    - Bluetooth between phone and earbuds
    - Smartwatch connected to mobile
    - Laptop ↔ Printer via Bluetooth
- 🔹 Features:
    - Short range
    - Low power consumption
    - Used for personal devices

2. 🔹 2. LAN (Local Area Network)
- A Local Area Network connects computers within a limited geographical area such as a home, office, or building.
- 📌 Examples:
    - Home Wi-Fi network
    - College computer lab
    - Office network
- 🔹 Characteristics:
    - High speed (100 Mbps – 10 Gbps)
    - Privately owned
    - Low latency

3. MAN (Metropolitan Area Network)
- A Metropolitan Area Network covers a city or large campus.
- 📌 Examples:
    - City-wide cable TV network
    - Government network across a city
    - University campuses
- 🔹 Characteristics:
    - Medium coverage
    - Higher speed than WAN
    - Managed by organizations or ISPs

4. 4. WAN (Wide Area Network)
- A Wide Area Network spans large geographical areas, even countries or continents.
- 📌 Examples:
    - The Internet
    - Bank networks across countries
    - Airline reservation systems
- 🔹 Characteristics:
    - Uses public and private communication links
    - Slower than LAN but covers large areas

5. WLAN (Wireless LAN)
- A Wireless Local Area Network uses Wi-Fi instead of cables.
- 📌 Examples:
    - Home Wi-Fi
    - Office wireless network

6. 6. CAN (Campus Area Network)
- Connects multiple LANs within a campus or institution.
- 📌 Examples:
    - University networks
    - Corporate campuses

## Network topology 
- refers to the physical or logical layout of devices (nodes) and connections in a computer network — in simple words, how computers are connected.
### 🔹 Types of Network Topologies
1. 1️⃣ Bus Topology
- 📌 All devices share a single communication cable (backbone).

2. 2️⃣ Star Topology
- 📌 All devices connect to a central hub/switch

3. 3️⃣ Ring Topology
- 📌 Devices connected in a circular fashion.

4. 4️⃣ Mesh Topology
- 📌 Each device connects to every other device.

5. 5️⃣ Tree Topology
- 📌 Hierarchical structure (combination of star + bus).
        Root
       /    \
     Hub     Hub
    /  \    /  \
   PC  PC  PC  PC

6. 6️⃣ Hybrid Topology
- 📌 Combination of two or more topologies.

## 🌐 OSI MODEL (Open Systems Interconnection Model)
- The OSI Model is a 7-layer **conceptual** framework that explains how data is transmitted from one computer to another over a network.
- It was developed by ISO (International Organization for Standardization) to standardize communication between different systems.

### 🔷 Why OSI Model is Important?
- Standardizes networking communication
- Helps understand how data flows
- Makes troubleshooting easier
- Acts as a reference model for network design

## 🧱 The 7 Layers of OSI Model (Top → Bottom)
- Topmost layer – closest to the user.
| Layer No. | Layer Name   | Main Function                        |
| --------- | ------------ | ------------------------------------ |
| 7         | Application  | User interface & network services    |
| 6         | Presentation | Data format, encryption, compression |
| 5         | Session      | Session management                   |
| 4         | Transport    | Reliable data transfer               |
| 3         | Network      | Routing & logical addressing         |
| 2         | Data Link    | Framing & MAC addressing             |
| 1         | Physical     | Transmission of raw bits             |

> “All People Seem To Need Data Processing”

1. 🔹 Layer 7 – Application Layer
- Topmost layer – closest to the user.
- Functions:
    - Provides network services to applications
    - Enables user interaction with network
- Examples:
    - HTTP / HTTPS
    - FTP
    - SMTP
    - DNS
    - SSH : 
        - SSH (Secure Shell) is a secure network protocol used to remotely access and manage another computer over an unsecured network (like the Internet).
        - Example : Linux Machine of AWS from my mac.
            - Connects Application layer of Linux in our machine.
        - 👉 It provides encrypted communication between a client and a server.
    - WebSockets Connection :
        - uses HTTP for initial Hnadshake.

2. 🔹 Layer 6 – Presentation Layer
- Ensures data is readable by the receiving system
- guided by HTTPS (SSL/TLS)
- Functions:
    - Data translation : 
    - Encryption & decryption : 
    - Compression : Reduces the size of data before transmission to save bandwidth and improve speed.
- 📌 Example: converting ASCII to Unicode
    - Big-endian ↔ Little-endian

3. 🔹 Layer 5 – Session Layer
- Manages sessions between two devices
- Functions:
    - Session establishment
    - Session maintenance
    - Session termination
    - Synchronization (checkpoints)

- These 3 are one in TCP/IP Protocol.

4. 🔹 Layer 4 – Transport Layer
- Ensures reliable data delivery
- The Transport Layer is responsible for end-to-end communication between applications running on different hosts.
> It ensures that data sent from the source arrives correctly, completely, and in order at the destination.
- Functions:
    - Segmentation & Reassembly : 
        - Breaks large data into smaller units called segments
        - Reassembles them at the receiver side in correct order
    - 2️⃣ Port Addressing (Process-to-Process Delivery)
        - Uses port numbers to identify applications
        - Ensures data reaches the correct process, not just the device
            - 📌 Example:
                - HTTP → Port 80
                - HTTPS → Port 443
                - FTP → Port 21
    - Error control
    - Flow control : sync of send and recieve.
        - Uses window size mechanism.
        - Ensures data packets are delivered in correct order
        - Uses sequence numbers
- Protocols:
    - TCP (reliable)
    - UDP (fast, unreliable)

 
5. 🔹 Layer 3 – Network Layer
- Handles routing of data packets.
- The Network Layer is responsible for delivering data from the source host to the destination host across multiple networks.
- Functions:
    - 1️⃣ Logical Addressing (IP Addressing)
        - Assigns logical addresses (IP addresses) to devices
        - Helps identify source and destination uniquely
    - 2️⃣ Routing
        - Determines the best path for data to travel from source to destination
        - Uses routing algorithms and routing tables
        - 📌 Example:
            - Shortest path
            - Least congestion
            - Fastest route
    - Packet forwarding : Forwards packets from one router to another until destination is reached
    - 5️⃣ Fragmentation & Reassembly
        - Breaks large packets into smaller ones (fragmentation)
        - Reassembles them at destination
- Protocols:
| Protocol              | Purpose                       |
| --------------------- | ----------------------------- |
| **IP (IPv4 / IPv6)**  | Logical addressing & routing  |
| **ICMP**              | Error reporting & diagnostics |
| **ARP**               | IP → MAC address mapping      |
| **RARP**              | MAC → IP (obsolete)           |
| **IGMP**              | Multicast management          |
| **Routing Protocols** | RIP, OSPF, BGP                |

6. 🔹 Layer 2 – Data Link Layer
- The Data Link Layer is responsible for node-to-node (hop-to-hop) communication.
- Functions:
    - Framing : 
        - Divides data into frames
        - Adds header and trailer
            - 📦 Frame = Header + Data + Trailer
    - Error detection :
        - CRC (Cyclic Redundancy Check)
        - Checksum
    - MAC addressing : 
        - Uses MAC (Media Access Control) addresses
        - Each device has a unique 48-bit MAC address(00:1A:2B:3C:4D:5E)
    - Flow control
- Sublayers:
    - LLC (Logical Link Control)
    - MAC (Media Access Control)

### 🔹 Data Link Layer Devices
| Device | Role                               |
| ------ | ---------------------------------- |
| Switch | Forwards frames using MAC address  |
| Bridge | Connects LAN segments              |
| NIC    | Interface between device & network |

### 🔹 Data Link Layer Protocols
| Protocol              | Used In              |
| --------------------- | -------------------- |
| Ethernet (IEEE 802.3) | LAN                  |
| Wi-Fi (IEEE 802.11)   | Wireless LAN         |
| PPP                   | Point-to-Point links |
| HDLC                  | WAN links            |


7. 🔹 Layer 1 – Physical Layer
- Deals with raw bits transmission
- Functions:
    - Bit Transmission
        - Converts digital data (0s and 1s) into:
            - Electrical signals (copper cable)
            - Light signals (fiber optic)
            - Radio waves (Wi-Fi)
    - Defines how bits travel.: 
        - Examples:
            - Twisted Pair Cable (Cat5, Cat6)
            - Coaxial Cable
            - Fiber Optic Cable
            - Wireless (Radio waves)
    - Defines how fast data is sent.
    - How 0s and 1s are represented:
        - Voltage levels
        - Light pulses
        - Frequency changes
    - Defines physical layout:
        - Bus
        - Star
        - Ring
        - Mesh
