## AI / ML
> Artificial Intelligence (AI) is the broader concept of making machines intelligent.
> Machine Learning (ML) is a subset of AI that enables machines to learn from data.

# Artificial Intelligence (AI) 
> is the field of computer science that focuses on building systems that can perform tasks which normally require human intelligence.

## Generative AI 
- is a type of artificial intelligence that can create new content—such as text, images, code, audio, or video—based on patterns learned from existing data.
> Generative AI learns from data and generates new, original outputs that resemble the data it was trained on.

### 🔍 How It Works (High Level)
- Train on large datasets (text, images, etc.)
- Learn patterns and relationships
- Generate new content by predicting what comes next
- Common models:
    - Large Language Models (LLMs) for text
    - Diffusion models for images
    - GANs (older but important concept)
- 
| Traditional AI        | Generative AI          |
| --------------------- | ---------------------- |
| Predicts / classifies | Creates new content    |
| “Is this spam?”       | “Write an email”       |
| “Cat or dog?”         | “Generate a cat image” |

### OpenAI’s Generative Pre-trained Transformer (GPT)
- 🧠 What “GPT” Means
- Generative → Creates new content
- Pre-trained → Trained on large datasets before use
- Transformer → Uses transformer neural network architecture

> GPT-5 is a more advanced AI model that understands and generates text (and other content) better than GPT-4.

## ML

### 5️⃣ Types of Machine Learning
1. Supervised Learning
- Data has labels
- Examples:
    - Spam detection
    - Price prediction
- Algorithms:
    - Linear Regression
    - Logistic Regression
    - Decision Tree
    - Random Forest
    - SVM

2. Unsupervised Learning
- No labels
- Finds patterns
- Examples:
    - Customer segmentation
    - Anomaly detection
- Algorithms:
    - K-Means
    - Hierarchical Clustering
    - PCA

## AGI vs Current AI (Very Important)
### 🔸 Current AI (Narrow AI)
- Designed for specific tasks
- Cannot generalize beyond training
- Examples:
    - Chatbots
    - Recommendation systems
    - Face recognition
- 👉 This is what we use today

### 🔹 AGI (General AI)
- Can reason, plan, learn, and adapt
- Works across multiple unrelated tasks
- Learns like a human
- 👉 AGI does NOT exist yet
